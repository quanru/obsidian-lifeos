# 1.29.1 发布记录

范围：独立开源插件的默认主题、选择器、窄屏交互、任务显示修复。用户已授权手机验收、主库安装和正式发布。

基线：1.29.0。开发目录 main，远端 main 已核对一致。复用上一轮逻辑测试，版本调整后固定附件并在真实手机与桌面验收。

尚未发布。耗时与 token 未计量；不运行远端 CI。

12:36 主库同时启用 Pro 时发现 LifeOS / PeriodicPARA 两个查询语言已占用，开源版因此无法完成加载。新增 LifeOSOpen 独立入口，保留占用中的兼容别名和全局 helpers；90 项测试通过，主库启用正常。该新修复使原候选附件失效，重新构建并核验。

12:43 Obsidian 主应用更新到 1.14.4 并移除了 1.14.3 runtime，原隔离回归入口报文件不存在。改用实际 1.14.4 runtime 后完整回归通过，没有放宽断言。

Android Midscene 两次长任务出现仓库详情和命令面板定位循环，未完成操作，均有界结束。切换为短任务并按截图纠正；仅测试笔记被重命名，无用户主库受影响。没有增加 replanning 上限或读取私人认证信息。

12:52 最终手机界面发现主题选择器操作被软键盘遮挡；使用宿主 keyboard-height 调整可用区域后，键盘上方应用按钮可见并已成功应用。全屏按钮位置已修复。

12:58 手机最终附件哈希核对通过，保存、完成回写、重启保留和新增关联通过。测试会话按 30 分钟上限结束并释放锁。另一会话随后占用安卓设备，恢复前一测试库按设备锁排队，不跨锁操作。

当前测试总数 90。最终桌面回归第一次被宿主信任按钮加载/移除的瞬时状态阻断，限定仅在插件已加载时接受该 DOM 变化，第二次回归全部通过，无绕过功能断言。npm 的 Midscene 1.15.1 依赖暂不可解析，后续使用已核验的 1.15.0 缓存和截图驱动的 ADB 操作，无需改网络。

发布完成：https://github.com/quanru/obsidian-lifeos/releases/tag/1.29.1。代码提交 11644f14cdcde6c7e6717395e4fa4aaea5a7f427；正式 tag 指向同一提交，4 个公开下载附件的字节哈希及 GitHub digest 均匹配。未执行远端 CI。

安卓设备锁释放后由 Tapilot 安装任务接管，已取消本任务排队中的旧前台恢复步骤，避免改变对方的验收界面。独立手机测试库仍保留，主库已安装新版。主库配置备用副本因与原配置字节相同且验收已完成而删除，仅保留旧插件二进制备份。
