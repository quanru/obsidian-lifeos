# 从免费版切换到 LifeOS Pro

免费版适合日常记录：快速记录、基础任务录入、主题关联均完整可用。需要在日历中安排任务、统筹多个项目或使用高级列表时，可以了解独立收费的 LifeOS Pro。购买不是使用本插件的前提。

## 切换步骤

1. 备份整个知识库，包括 `.obsidian` 配置目录。
2. 打开免费版设置的「使用与升级」，展开「切换前查看配置」，记下周期笔记目录、记录标题和四个 PARA 目录。此处仅展示本插件配置，不检测或修改 Pro。
3. 从 [购买页面](https://lifeos.md/zh/plugin/lifeos/pricing) 获取独立的 LifeOS Pro 和激活说明，按购买后提供的步骤安装并激活。插件目录为 `.obsidian/plugins/lifeos-pro/`，不要覆盖免费插件所在的 `.obsidian/plugins/periodic-para/`。免费插件不会自动安装、更新或解锁 Pro。
4. 在 Pro 中手动配置相同目录和记录标题。检查已有笔记能否被识别，并逐项核对任务语法、主题标签、模板与日期命名；相同 Markdown 文件不代表两个插件的所有扩展语法完全兼容。
5. 使用几条测试记录核验查看、编辑和跳转。测试期间避免两个插件同时执行同步、自动时间戳等写入操作。
6. 确认 Pro 能正常使用后，停用免费插件。保留原文件和备份，无需搬动笔记或上传笔记内容。

接管指南提供人工核对步骤，不会自动转换数据、迁移私有配置或转移激活信息。若要切回免费版，先停用 Pro、再启用免费版，核验新增笔记语法；如有差异，从备份恢复或手动调整。

## 一个使用场景

先在免费版快速记下「发布新版插件」，关联项目主题，并写下一个基础待办。日常只需要记录和回顾时，继续使用免费版即可。当多个项目开始争用时间，需要统一安排日期、查看跨项目任务时，再考虑 Pro 的日历、任务视图和高级列表。
