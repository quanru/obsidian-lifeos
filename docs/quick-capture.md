# 快速记录

在命令面板运行“快速记录”或“快速任务”，也可以点击左侧的消息图标。两个命令打开同一个窗口，只是初始输入模式不同。保存后窗口保持打开并沿用当前命令的记录或任务类型，可以连续输入；默认主题继续生效。

内容写入今日日记中设置的“日常记录”标题下，历史列表读取周期目录中的日记。整个流程无需 Dataview。旧版快速记录生成的条目会直接出现在列表中，无需迁移或导入。新记录带标准 Obsidian 块引用标识，用于区分内容相同的记录；窗口中不会显示这些标识。

## 输入与浏览

- 默认使用 Obsidian 原生实时预览编辑器，输入 Markdown 时直接呈现格式、图片和任务。底部只保留主题关联和保存，编辑卡片时增加取消。格式、任务清单和笔记链接直接使用 Markdown 语法或 Obsidian 原生快捷键；右键编辑区，在原生菜单中切换 Markdown 源码与实时预览。Ctrl/Cmd + Enter 保存。编辑区只管理草稿，不会自动写入日记。当前版本若不支持嵌入原生编辑器，会提示并退回 Markdown 输入。
- 记录和任务由“快速记录”“快速任务”命令分别进入，任务窗口标题会标明类型。任务保留标准 `- [ ]` 语法，也可以在一条记录中加入多个子任务。
- 通过 `#标签` 给记录分类；搜索、标签下拉多选和日期筛选可以组合使用。日期可选全部、今天、最近 7 天、最近 30 天及自定义范围，选择自定义后才显示起止日期。多个标签按“全部包含”匹配，日期包含边界当天。
- 历史记录使用紧凑卡片，时间、主题和来源同行展示；长内容自然撑开，窄窗口自动换行。记录按日期分组并倒序显示，同一天按日记中的位置倒序；滚动到列表末尾自动追加下一批 25 条，也可聚焦末尾的“加载更多”按 Enter 或空格。
- 图片可直接从系统剪贴板粘贴。每张图片须小于 20 MB，新版使用 Obsidian 的附件位置设置和链接格式；缺少附件路径 API 的旧版本会将图片存放在库内 `LifeOS Attachments`，遇到同名文件会自动加序号。
- 输入 `[[` 使用 Obsidian 的原生笔记链接补全，插入普通 Obsidian 链接。
- 点击全屏按钮扩大窗口；小窗口下筛选和工具栏会换行。

## 快捷键和默认主题

在插件设置的“快速记录”页点击“记录快捷键”或“任务快捷键”，进入 Obsidian 的快捷键设置，为对应命令分配按键。默认不占用全局快捷键；窗口内仍使用 Ctrl/Cmd + Enter 保存。

点击“选择主题”多选常用 PARA 主题。以后打开快速记录、快速任务，以及连续保存后的下一条草稿，都会自动带上这些主题的当前标签；编辑历史记录时不会添加默认标签。可以在单条草稿中修改或取消关联，关闭后再次打开仍按默认设置初始化。只有默认标签、没有正文的草稿不会被保存。

默认设置只保存主题索引路径，不缓存标签。主题标签变化后，新草稿使用最新标签；主题被删除、改名、移出配置的 PARA 目录、移除标签，或 PARA 功能被关闭时，会跳过对应主题。设置页会提示不可用的主题；可重新选择或点击“清除默认主题”。现有日记无需改写。

## 主题关联

在输入区或历史记录卡片点击“关联主题”，搜索并多选项目、领域、资源或存档。选择器读取插件设置中 PARA 目录下的主题索引笔记：`readme` 模式使用 `主题目录/README.md`，`folderName` 模式使用 `主题目录/主题目录.md`。索引笔记须在 YAML frontmatter 中设置 `tags`，标签可用字符串或数组；模板文件、普通子笔记、无标签索引和格式错误的 YAML 不会成为候选。

例如，项目索引的 `tags: [工作, 发布]` 会让选择器为记录加上 `#工作 #发布`。记录包含某个主题的全部标签时，卡片就显示这个主题，可以直接打开索引笔记。未开启 PARA 时不会列出候选。

输入区关联只更新草稿；保存记录后才写入日记。历史卡片关联直接修改那一条记录，并走同样的原子写入和源内容冲突检查。选择器取消不改变内容，主题目录或标签在选择器打开期间发生变化时，会拒绝套用过期结果；输入草稿也会在应用前重新核对。

更换主题时，只移除原关联中不再需要的标签，保留普通标签、正文、代码示例和笔记链接。多个主题共享标签时，标签本身无法唯一表示主题身份，因此它们可能同时匹配。选择器会提示这一点，且不会移除其他已选主题仍需的共享标签。需要区分主题时，请给索引笔记添加独有标签。

## 编辑与保护

历史卡片提供主题关联、复制、编辑、删除和打开日记。复制包含正文和任务完成状态，不包含时间和内部块标识；双击卡片正文也可定位到源日记，链接、按钮、复选框等交互控件不会触发此导航。任务复选框会修改对应日记里的任务状态。删除前会显示确认窗口；取消不会修改日记。

修改和删除通过 Obsidian 的原子 `vault.process` 完成。执行前重新读取日记，并检查整个原始记录块；记录移动但内容没有变化时仍可定位。记录已被外部修改、删除，或者同一标题下存在无法区分的重复块时，会拒绝操作并保留编辑草稿。刷新后可以重新选择记录。周回顾和其他日记内容不会被操作。

编辑直接在原卡片内进行，保留时间、已有块引用标识和已完成任务状态。取消会丢弃这张卡片的编辑内容，顶部的新草稿始终保持原样。筛选、滚动加载或外部刷新时，正在编辑的卡片仍会保留；若筛选不再包含它，会单独显示，避免丢失未保存内容。关闭窗口会丢弃尚未保存的文本草稿。粘贴图片时附件立即写入库；取消记录、关闭窗口或删除卡片不会自动删除附件，避免误删被其他笔记引用的图片。

## 与 Pro 的关系

这是开源仓库中的独立实现，没有引入 Pro 源码、共享包、付费配置或构建产物。原生实时预览编辑器和 PARA 主题关联均在此仓库独立实现。使用 Obsidian 宿主的编辑器能力和普通 Markdown 标签，不公开或依赖 Pro 内部源码。普通笔记关联仍使用 Obsidian 链接。

首次浏览会读取周期目录下的日记。窗口内缓存已读日记，库的创建、修改、删除和重命名事件会触发刷新。历史量很大的库首次加载仍可能需要等待；分页限制界面渲染数量，不限制读取的日记总数。
