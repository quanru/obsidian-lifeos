# 普通主题笔记验收记录

验收日期：2026-10-10。开发仓库为独立开源版 `obsidian-lifeos`，示例在独立 `obsidian-example-lifeos` 仓库维护，两个仓库均保留在本地 main。本次未推送、未发布、未修改真实用户知识库。

## 实现范围

普通主题笔记无需 PARA 四类目录。主题启用与 PARA 模式分别配置；创建、标签关联、默认主题、基础聚合、原生主题列表搜索、日记快照及名称同步已独立实现。普通与 PARA 的目录、模板及命名设置分别保存。旧版禁用 PARA 的用户保持主题功能关闭，升级不会搬动旧笔记。

记录关联采用任一标签匹配，新增关联只添加首标签；共享标签仍按标签本身识别。日记记录和任务查询使用快速记录的同一套标题边界，过滤习惯统计及其他子标题中的条目。任务勾选写回原笔记。冲突不覆盖目标，也不回滚用户已完成的手动重命名。

没有将 Pro 源码、依赖配置、发布配置或付费插件产物引入开源仓库。AI 和时间投入统计不在本次范围。

## 静态与示例验证

- `dev-gate run -- pnpm build`：TypeScript 和生产构建通过，包含最终重命名调度改动。
- `dev-gate run -- pnpm test`：85 项测试通过，0 失败。
- 对新增主题模块及受影响创建、设置、查询模块执行定向 Biome 检查通过；最终 main 与主题模块补充检查通过。
- 两个仓库 `git diff --check` 通过。
- 示例生成检查：770 个文件、10 种语言，每种语言 4 类库。
- 示例打包：10 份 ZIP；逐包核对四类库目录，未包含插件二进制。

四类库为 LifeOS Vault、LifeOS Blank Vault、LifeOS Theme Vault 和 LifeOS Theme Blank Vault。普通主题示例包含主题索引、关联记录、任务、资料、相关主题，以及用于验证过滤的同标签习惯任务。

## 真实环境验收

使用 Obsidian 1.14.3、Dataview 0.5.68，在独立 profile 和临时中文主题示例库中安装开源仓库当前构建。启动参数包含 `--use-mock-keychain`，不接管真实用户库。仅使用本机现有 Obsidian harness 作为测试工具，没有复制该工具或商业插件产物到开源发布内容。

已通过：

- 普通主题设置显示，中文语言选择显示正确；截图核对布局与说明文字。
- 创建 `日语/日语.README.md`，标签写入属性。
- 主题页显示记录、任务、资料及相关主题；同标签习惯任务排除。
- 勾选主题任务后，日记源任务更新且查询刷新。
- 快速记录选择普通主题，新增首标签并写入当日日记。
- 创建日记时替换主题快照占位符，包含已有和新建主题。
- 原生主题列表搜索过滤结果。
- 文件夹改名同步带前缀 README 索引；同名索引改名同步文件夹。
- 同步目标重名时保留已有目录与手动改名文件，未覆盖。
- 切换 PARA 后识别项目，原项目快照仍有效，新增关联只添加首标签。
- 主页面无 pageerror。隔离实例退出、临时 profile / vault 清理。

Obsidian 的重命名可能弹出更新内部链接确认；测试库选择总是更新。插件的后续名称同步延后调度，让原重命名操作先完成。

本次活验证使用桌面中文界面；其余语言检查配置与文案完整性，未逐语言实测全部 UI，也未进行移动端实测。任务、记录和资料聚合继续依赖 Dataview；原生主题列表、创建和快速记录不依赖它。
