# 主题记录流程打磨验收

2026-10-11，独立开源仓库 main，基线 c5a768a56460a58d2f70a5aefccbf3f3f1c656f6。当前改动尚未提交、推送或发布，版本保留 1.29.0。未操作用户主库。

## 问题与修复

- 普通主题模式的默认主题按钮错误地依赖 PARA 开关，导致按钮不可用。改为依赖主题笔记开关，十种语言的提示也同步改正。
- 默认项错误地按照标签匹配重建选择，选择一个共用标签的主题会连带选择其他主题。默认项现在按笔记路径独立保存；记录关联继续保留按标签匹配的语义。
- 搜索无结果时原来提示添加 tags，即使库中已有有效主题。现在区分没有主题和搜索无匹配；清除搜索保留选择。
- 选择器每次勾选重建 DOM，导致键盘焦点丢失。现在原位更新勾选状态，保留焦点。
- 读取主题失败时原来提示草稿变化。现在提供准确失败说明及重试入口，保留输入。
- 多行快速任务在 Dataview 视图中显示内部 capture 块 ID。现在仅覆盖任务的 visual 显示字段，保留原文、行号和嵌套任务；主题任务、周期记录任务及已完成任务统一使用该显示处理。
- 窄窗口弹窗被 Obsidian 默认最大宽度限制，按钮触控区域较小。增加窄屏宽度及主要操作 44px 触控区域；短窗口可滚动到保存及历史，主题选择列表和底部操作保留可达性。
