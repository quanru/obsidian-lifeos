# LifeOS 1.29.1 发布前验收

2026-10-12，独立开源仓库 main。版本在 manifest、package、versions 三处一致。修复普通主题默认设置、共享标签默认项、主题搜索与读取恢复、键盘焦点、窄屏触控和任务块 ID 展示。

主库验收额外发现旧查询别名被其他插件占用时开源版无法完成加载。新增独立 LifeOSOpen 查询与全局辅助入口，保留被占用的 LifeOS / PeriodicPARA。未复制 Pro 源码、配置或二进制。

## 静态与桌面

生产构建与类型检查通过，90 项逻辑测试通过，定向 Biome / Prettier / diff 检查通过。最终附件固定在 .verify/release-1.29.1/artifacts。

真实 Obsidian 1.14.4、Dataview 0.5.68，在独立 profile 与示例测试库中验证默认项、共享标签、搜索恢复、键盘焦点、窄屏按钮、短窗口保存、卡片打开主题、独立 LifeOSOpen 查询、任务勾选写回与重新读取。完成前后源块 ID 保持一致，页面无 pageerror。测试实例与临时库已清理。

## Android 真机

Redmi K30 Ultra、Android 12，使用独立 LifeOS-OSS-Acceptance-1291 测试库，只安装当前开源附件与 Dataview。通过真实触摸和键盘输入验证：默认主题标签、记录/任务切换、软键盘弹出时保存、新增卡片、勾选源日记写回、重启后状态保留、主题选择与应用。最终附件三项 SHA-256 与手机安装文件一致。

手机验收发现全屏按钮与说明重叠，以及主题选择器底部被键盘遮挡；已调整按钮容器与位置，按宿主 --keyboard-height 预留可用高度，最终实机截图确认两项通过。

手机独立测试库保留供查看。未改动手机真实 LifeOS 笔记。iOS 和最低宿主版本未实测，不以 Android 或桌面结果替代。
