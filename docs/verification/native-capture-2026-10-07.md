# 原生快速记录验收

> 本文记录原生编辑器和主题关联的首轮验收；后续交互变化及当前产物验收见[快速记录交互对齐验收](capture-interaction-2026-10-07.md)。

实现位于独立的 `obsidian-lifeos` 仓库，未复制 Pro 源码、共享包、构建产物、依赖配置或商业配置。复用的是 Obsidian 宿主的编辑器能力，快速记录和主题关联逻辑在开源版独立编写。尚未提交、推送或发布。

## 功能和数据兼容

默认使用原生实时预览编辑器，支持 Markdown 源码切换、独立预览、撤销与重做、图片、任务和笔记链接。编辑器只持有草稿，显式保存才写入日记；无法初始化原生编辑器时提示并回退到 Markdown 输入。

PARA 主题选择器读取已配置目录中的主题索引及 YAML 标签，支持搜索、多选和打开索引。输入区关联更新草稿，历史卡片关联原子修改已有记录。取消不写入；草稿、索引标签或源记录变化时拒绝覆盖；共享标签保留其他已选主题所需的部分。

已有快速记录直接读取，无需批量改写。新记录增加标准块标识，编辑保留原时间、标识和任务状态。关闭窗口丢弃未保存文本；已上传附件保留，避免误删其他笔记引用的图片。

## 验证结果

- 完整测试通过 57 项；TypeScript 检查和生产构建通过，定向 Biome 检查及 `git diff --check` 通过。
- 在 macOS Obsidian 1.14.3 的独立 profile 和临时测试库运行，使用 mock keychain，不读取真实笔记；测试结束关闭本次实例并清理临时库。
- 实测原生格式呈现、笔记链接补全、源码切换后的选区与撤销/重做、显式保存、关闭后重新打开、图片、根任务和子任务。
- 验证等待及 Cmd+S 不会自动写入日记；主题多选、共享标签、主题目录变化及源记录变化保护通过。其他日记章节保持完整，renderer 无错误。
- 中文、繁中、英语、德语、西语、法语、葡语、日语、韩语和阿语界面及主题弹窗通过；中文和阿语的 480px 窄窗口已截图。阿语全屏按钮改到左侧，避免遮挡标题。
- 输入法组合状态的保护使用 `isComposing` 事件断言，未宣称完成实体输入法全过程验证。最低支持版本 1.4.0 仅核对公开 API 并提供附件回退，尚未做该版本运行实测；原生编辑器在宿主升级后仍需复核。

所有执行遵守本机 `dev-gate`，未触发远程 CI。最终运行记录包含被测产物 SHA-256：
