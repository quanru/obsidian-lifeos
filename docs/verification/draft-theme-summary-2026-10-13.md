# 快速记录的主题归属提示验收

本轮完善已有主题关联入口：输入区显示“关联主题”，选中后显示主题名称；多个主题显示首个名称与额外数量，悬停提示和无障碍标签包含全部名称。记录/任务切换与主题选择保持在同一工具栏，窄窗口按可用空间自然布局。仍使用现有普通 Markdown 标签关联，不强制 PARA，也没有新增配置或数据格式。

概要随主题选择、手动增删标签、目录刷新和历史记录编辑更新。保存后按既有默认主题规则重置新草稿；关联仍按实际标签匹配，共用标签可能同时显示多个主题。

补查历史编辑时发现原生 CodeMirror 输入可能被消费，容器的 DOM input 监听没有及时刷新归属提示。现已同时监听 Obsidian 的 editor-change，只处理当前草稿编辑器，并在文档状态提交后更新；关闭编辑器时解除监听。
