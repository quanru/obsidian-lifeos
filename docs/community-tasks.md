# 社区贡献任务

以下是可以直接整理为 GitHub issue 的任务草稿。每项可以独立完成；开始前先确认没有其他人正在处理。当前没有自动创建远端 issue。

## 补充快捷键配置教程

说明如何为“快速记录”“快速任务”配置快捷键，加入英文和中文示例。验收：截图来自无真实数据的测试库，命令名称与实际界面一致，README 有入口。

## 增加日期边界用例

补充闰年二月、季度首尾、ISO 第 53 周、带中文或英文后缀的日期格式用例。验收：测试运行于 `pnpm test`，检查实际路径和范围；发现行为问题时先说明预期。

## 检查窄屏和移动端操作

在真实 Obsidian 移动端或独立测试环境验证快速记录、初始化。验收：输入框、保存按钮均可操作；提供环境、关键截图和具体问题。修复尽量使用 Obsidian CSS 变量，不增加平台专属界面分叉。

## 改进回顾中的多行记录

目前回顾逐条展示列表行，多行记录的上下文可以进一步合并。验收：保留换行语义，跳过代码示例，不误把嵌套任务当作记录；加入对应回归测试，不改变源笔记。

## 增加设置诊断入口

集中展示模板是否存在、周期目录是否冲突、Dataview 当前状态。验收：只读检查，不输出配置中的 token，不自动覆盖文件；英文、简体、繁体文案齐全。
