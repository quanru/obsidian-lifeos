# 每周回顾

在 Obsidian 命令面板运行 LifeOS 的“每周回顾”，选择本周或上周，检查预览后点击“保存 / 刷新回顾”。这个功能不依赖 Dataview，也不要求安装周记模板。

## 汇总范围

周范围使用 ISO 周，周一至周日。汇总按配置的周期目录和日记格式查找七篇日记，包含日常记录标题下的列表记录，以及这些日记中当前已勾选、未完成的任务。代码块和 frontmatter 中的示例不计入。已勾选状态不代表任务恰好在这一周完成。

开启 PARA 后，项目部分列出配置的项目目录中、文件修改时间落在本周的 Markdown 笔记，排除项目模板。它提供近期活动入口，不推断项目完成比例。同步或导入也可能改变文件修改时间。

每条汇总都附有源笔记链接。任务以普通列表展示，不生成新的复选框，避免 Dataview 将它们计为额外任务。

## 保存和刷新

回顾保存在周记目录下，文件名为当前周记文件名加 `-Review.md`。原周记及其查询视图保持独立；旧周记不会自动迁移。

文件中这两个标记之间是自动汇总区域：

```markdown
<!-- lifeos:weekly-review:start -->

自动生成的内容

<!-- lifeos:weekly-review:end -->
```

把自己的总结写在标记区域之外，例如“我的回顾”标题下。刷新会原样保留区域外的文字。自动汇总区域内的手动改动会在刷新时被替换。

已有同名笔记缺少有效标记、标记次序错误或包含重复标记时，LifeOS 会停止保存并保留原文。请先重命名原笔记，再创建新的回顾。

## Dataview 提示

初始化、快速记录、快速任务和每周回顾无需 Dataview。旧有查询视图仍依赖 Dataview，会分别提示安装、启用或等待索引。处理后点击“重试”。

## 兼容性

最低支持 Obsidian 1.4.0，文件写入使用 `Vault.process`。周记创建、范围查询和日期选择统一使用 ISO 周；原设置中的 `gggg`、`ww`、`w` 按 ISO 周年和周序号解释，方括号内的文字保留。跨年边界处，旧版按地区周编号生成的笔记可能与新文件路径不同，请核对后手动整理。
