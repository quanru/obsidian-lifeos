# When LifeOS Pro helps

Capture, task entry, themes and basic queries remain free. In **Using LifeOS**, expand **When is Pro useful?** to compare three situations: planning a busy week, finding items in longer lists, and coordinating projects.

![Scenario comparison in settings](assets/upgrade-value/en.png)

Pro adds calendar scheduling, searchable and filterable advanced lists, and a home workflow view. Keep using the open-source plugin when its features meet your needs. Missing Dataview or an unfinished index is a dependency issue to resolve using the query guidance.

LifeOS Pro alone does not include AI. AI requires the separate DeepAsk plugin and your own supported model service or CLI.

Before switching, back up your vault and review the read-only folder settings under **Review settings before switching**. Install Pro separately, configure matching folders and headings, then test with a few notes. Avoid concurrent writes from both plugins. Once satisfied, disable the open-source plugin. Markdown files remain in place, but custom syntax and templates need manual checking; no automatic migration or activation transfer is provided.

The comparison link carries only a fixed source parameter. This section does not collect usage events or upload vault data.
