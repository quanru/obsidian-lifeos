## Theme notes without mandatory PARA

- Create and organize plain theme notes in your own folder, or keep your existing PARA workflow. Each mode retains its own folders, naming and templates.
- Associate quick records and tasks with themes, select default themes, and find linked records using any matching theme tag. New associations add the theme's first tag.
- Collect theme tasks, records, reference notes and related themes. Completing a task updates its source note. Daily queries exclude habit entries using the same heading boundaries as quick capture.
- Search native theme lists, create daily theme snapshots, and optionally synchronize theme folder and index names. Name collisions never overwrite existing notes.
- Keep existing notes, custom templates and PARA snapshots. Users who disabled PARA keep theme notes disabled until they enable the feature.

[Companion Examples 1.20.0](https://github.com/quanru/obsidian-example-lifeos/releases/tag/1.20.0) provides four vault variants in each of ten languages: PARA example, PARA blank, plain-theme example and plain-theme blank. Install LifeOS and Dataview separately; plugin binaries are not bundled.

Native theme lists, creation and quick capture work without Dataview. Task, record and file query blocks require Dataview. This release was tested on macOS with Obsidian 1.14.3; mobile and the minimum supported host version were not runtime-tested. No Pro source code or paid plugin assets are included.
