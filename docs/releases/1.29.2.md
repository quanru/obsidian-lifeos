# LifeOS 1.29.2 — Clearer capture and theme overviews

Open-source LifeOS update.

- See associated themes directly in Quick capture, including multiple-theme counts and updates while editing tags or saved records.
- Focus new theme overviews on unfinished tasks, with result counts, inclusion rules, useful empty states, source links and task writeback.
- Upgrade standard queries in existing theme notes and configured templates through a selective preview. Handwritten content and custom queries are preserved, and changes made after preview require a fresh confirmation.
- Get actionable guidance for missing or disabled Dataview and missing theme tags. Queries recover automatically when Dataview finishes indexing.
- Refresh reference notes when the index changes, exclude theme indexes from resources, and avoid matching unrelated tags with similar prefixes.
- Compare free and Pro workflows through optional scenarios in settings, with a clear explanation of the separate AI requirement.
- Start capturing from workspace setup without selecting a complete organization system, and use quieter controls in capture and settings.

Quick capture, theme creation and native theme lists work without Dataview. Task, record and resource queries require Dataview to be installed and enabled. Existing templates are never upgraded automatically.

The independent example repository includes Chinese and English learning and project walkthroughs for the new theme overview. Download the companion LifeOS Examples 1.21.0 release for learning and project walkthroughs.

Requires Obsidian 1.4.5 or newer. Candidate runtime checks use macOS with Obsidian 1.14.4; this round does not claim minimum-version or mobile runtime coverage.
