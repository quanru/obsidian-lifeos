# LifeOS 1.28.0

- Start a workspace in ten languages: English, Simplified Chinese, Traditional Chinese, German, Spanish, French, Portuguese, Japanese, Korean, and Arabic. Setup, folder settings, templates, capture, and weekly review use the selected language; Arabic dialogs support right-to-left layout.
- Capture continuously with native live preview, Markdown source and preview modes, images, tasks, and note links. Browse records by date, search and combine tag/date filters, edit in place, copy, and open the source daily note. PARA themes and optional default themes use ordinary Markdown tags.
- Configure capture shortcuts through Obsidian's shortcut settings. No global shortcuts are assigned by default.
- Review this week or last week, collect records and tasks, and refresh a separate review note while preserving personal reflections. Setup, capture, and weekly review work without Dataview; query views provide installation, enablement, and indexing guidance.
- Preserve existing templates and notes during setup or repair. Atomic writes and conflict checks protect existing records. Weekly notes and reviews consistently use ISO weeks, including year boundaries and vault-root paths.

## Getting started

Download the matching example or blank vault from [LifeOS Examples 1.11.0](https://github.com/quanru/obsidian-example-lifeos/releases/tag/1.11.0). Each language ZIP contains both variants. Install LifeOS and, for query views, Dataview from Obsidian Community plugins.

Requires Obsidian 1.4.0 or newer. This release was tested on macOS with Obsidian 1.14.3; mobile and the minimum supported version were not runtime-tested. Native capture falls back to Markdown input if the host editor cannot initialize. Existing notes are not translated or renamed, and older weekly note names are not migrated automatically.

Unsaved text is discarded when capture closes. Uploaded images remain in the vault, including when a draft is cancelled or a record is deleted.
